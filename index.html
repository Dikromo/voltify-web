FAQ

Pertanyaan yang Sering Diajukan

Segala hal yang perlu Anda ketahui tentang penggunaan Voltify.

Bagaimana Voltify menghitung estimasi sisa hari token?
Voltify menghitung laju pemakaian (burn-rate) berdasarkan selisih riwayat log token Anda dan total watt beban alat listrik terdaftar. Saldo token berkurang secara real-time berdasarkan burn-rate harian tersebut.
Apakah data saya disimpan di server online?
Tidak. Voltify menganut prinsip Offline-First. Seluruh data profil meteran, riwayat transaksi, dan beban alat disimpan 100% secara lokal di HP Anda menggunakan database SQLite yang terenkripsi.
Apakah Kunci API Volt AI (Gemini) saya aman?
Sangat aman. Kunci API disimpan di penyimpanan terenkripsi hardware (EncryptedSharedPreferences / Keychain) dan hanya dikirimkan secara langsung ke endpoint resmi Google Gemini API.
Apakah Voltify merupakan aplikasi resmi PLN?
Bukan. Voltify adalah aplikasi asisten mandiri (third-party) untuk membantu pengguna memantau dan mengestimasi pengeluaran listrik secara independen.
Mengapa ada iklan di Voltify & bagaimana cara menghilangkannya?
Voltify menampilkan iklan banner dan native dari Google AdMob untuk mendukung pengembangan versi gratis. Anda dapat menikmati pengalaman 100% bebas iklan dengan berlangganan Voltify Pro.
Bagaimana cara kerja akses Kalkulator Belanja Listrik?
Pengguna gratis dapat membuka akses Kalkulator Belanja selama 10 menit dengan menonton 1 video iklan (Rewarded Ad) hingga selesai. Bagi pengguna Voltify Pro, Kalkulator Belanja dapat diakses 100% tanpa batas waktu selamanya tanpa iklan.
